## Tech Stack

**Next.js** · **React** · **viem** · **wagmi** · **Tailwind CSS** · **TypeScript**

## Getting Started

```bash
# clone
git clone https://github.com/nickthelegend/molfi-x402-marketers.git
cd molfi-x402-marketers

pnpm install
pnpm run dev
pnpm run start
pnpm run build
pnpm run test
```
